# Portfolio-Web: Sirawish "Champ" Wuvanich

This project is a professional, single-page portfolio for Sirawish "Champ" Wuvanich, a Marketing Manager and Growth Strategist.

## Core Identity & Aesthetics
- **Theme:** "Muji-inspired Minimalist Creative".
- **Visuals:** Neutral tones (off-white `#fdfcf8`), clean typography (Inter), and generous whitespace.
- **Tone:** Professional, clean, and innovative.

## Technical Stack
- **Languages:** Pure HTML5, CSS3, and Vanilla JavaScript.
- **Dependencies:** None (No frameworks like Tailwind or React, keeping it simple for non-programmers).
- **Fonts:** Google Fonts (Inter).

## Key Features
- **Multi-language Support:** English (EN) and Thai (TH) toggle using `data-en` and `data-th` attributes in HTML.
- **Scroll Reveal:** Smooth fade-in animations as the user scrolls.
- **Smooth Navigation:** Internal links use smooth-scroll behavior.
- **Responsive Design:** Optimized for both mobile and desktop.

## Deployment Strategy
- **Platform:** GitHub Pages.
- **Method:** "Deploy from a branch" (Simplest method).
- **Requirements:** `index.html` must remain in the root directory.
