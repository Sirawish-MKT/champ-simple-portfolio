# Sirawish "Champ" Wuvanich | Marketing Portfolio

A minimalist, high-impact portfolio website built with a "Muji-inspired" aesthetic. This site showcases the work and achievements of Sirawish Wuvanich, a Marketing Manager and Growth Strategist.

## ✨ Features

- **Muji-Inspired Design:** Minimalist, clean, and professional aesthetic using neutral tones and generous whitespace.
- **Bilingual Support (EN/TH):** Integrated language switcher to toggle between English and Thai content seamlessly.
- **Scroll Animations:** Subtle "scroll reveal" effects for a premium feel.
- **Responsive Layout:** Fully optimized for mobile, tablet, and desktop viewing.
- **Fast Performance:** Built with pure HTML5, CSS3, and Vanilla JavaScript (No heavy frameworks).

## 🚀 Key Achievements Featured

- **XMBA 100 Seats:** Successful management of 100-seat cohorts.
- **XPerience 35 Seats:** Leadership in recruitment and coordination.
- **Community-Driven Growth:** Strategic community initiatives at eddu.
- **Upselling Excellence:** High-conversion strategies across specialized courses.

## 🛠️ Technology Stack

- **HTML5:** Semantic structure for SEO and accessibility.
- **CSS3:** Custom styling with Inter typography.
- **JavaScript:** Vanilla JS for animations and language switching.
- **Deployment:** Hosted on GitHub Pages.

## 📂 Project Structure

- **`/docs`**: Contains all public website files (HTML, CSS, JS).
  - `index.html`: Main content and bilingual data attributes.
  - `style.css`: Minimalist styling and responsive grid.
  - `script.js`: Language toggle logic and scroll animations.
- **`/Plan`**: Project management and planning documentation.
  - `GEMINI.md`: Project documentation and status tracking.
  - `port-web-plan.md`: The original implementation blueprint.
- `README.md`: Project overview and repository guide.
